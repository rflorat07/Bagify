# Bagify - Ecommerce Bag Shop App

An application built with a **Clean Architecture** and **Feature-First** approach using **Riverpod** for state management.

## 🎯 Implemented Features:

* Product listings, details, cart, and checkout flows
* Wishlist, order tracking, and user profile screens
* Clean, elegant, and fashion-focused design
* Perfect for bag brands, fashion startups, and e-commerce
